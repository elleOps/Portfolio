Hash Identifier

A Python tool that identifies the algorithm behind an unknown hash string.

The problem

During forensic triage, investigators often come across a hash with no context attached — no easy way to tell whether it's MD5, SHA-1, SHA-256, or something else, which slows down every step that follows.

The approach

Matches length, character set, and structural patterns against a library of known hash formats, then returns likely candidates ranked by confidence — a small utility built entirely in Python for a real, repeatable task.

Early Planning

Smart Contract Auditor

A planned tool for surfacing common vulnerabilities in Solidity smart contracts.

The problem

Smart contracts increasingly sit at the centre of the financial crime I investigate day to day, and their vulnerabilities are usually only found after the money has already moved.

The approach

Scan contract code for known vulnerability patterns — reentrancy, integer overflow, access-control gaps — as a first pass that flags what deserves closer manual review.
